# CGJ Assignment 1 (Math Challenge) Group 20

## Build & run
Open **Visual Studio 2022 → File → Open → Folder…** and select this folder.
Wait for CMake configuration to finish, set the startup item to **`sample.exe`**,
then press **Ctrl+F5**.

Or from a **Developer Command Prompt for VS 2022** in this folder:

```bat
cmake -S . -B build
cmake --build build --config Release
build\Release\sample.exe
```
